# Perfect Diagnostic Ultrasound - Chicago

Interactive multi-page website demo for Perfect Diagnostic Ultrasound.

## Live Demo
Visit the live demo on GitHub Pages:
https://jasimkarim08.github.io/Perfect-Diagnostic-Ultrasound/

## Project Structure
- `index.html` - Root entrypoint redirecting to `html/index.html`
- `html/` - All primary website pages (`index.html`, `about.html`, `services.html`, `physicians.html`, `reviews.html`, `contact.html`, `booking.html`)
  - `services/` - Individual modality ultrasound subpages
  - `ghl/` - Production GoHighLevel body snippets & tracking code
- `images/` - Brand photography and official SVG logos
- `styles.css` - Global design system and typography styles
- `script.js` - Global interactive JavaScript (language toggle, modal drawers, mobile navigation)
